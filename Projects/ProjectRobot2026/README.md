# Verified Regulation Management for a Mobile Robot Fleet (P + PObserve)

Starter kit for the graduate project. Two robots cross a three-zone corridor head-on, and a human picker needs zone 1 closed. The architecture combines **distributed regimentation** (one controller per zone admits or denies access locally) with **centralized adaptation and sanctioning** (one coordinator, one obligation manager). See section 4 of the specification.

**The assignment** (goals, experiments E0–E9, 45-day schedule, deliverables, grading) is in [`ASSIGNMENT.md`](ASSIGNMENT.md); section 8 of the specification is authoritative.

## Specification

The full project specification (background on P, multi-agent systems, norms and regulation management; system description; experiments; work plan) is in [`SPECIFICATION.md`](SPECIFICATION.md). Open [`SPECIFICATION.html`](SPECIFICATION.html) in a browser for a formatted version with figures.

## Quick start

```bash
cd MobileRobots
p compile
p check -tc tcFleetTwoPhase -s 100000
p check -tc tcFleetNaive -s 10000
p check -tc tcFleetSanctionFairness -s 10000

# preview monitor results on a log without any toolchain
python3 ../tools/simulate_logs.py --scenario fleet --policy naive --seed 2 --out fleet.log --check
```

## Status

**Independent evaluation, 21 October 2026** (P 3.1.0.0, .NET SDK 8.0.426, OpenJDK 17.0.20.8): `p compile` succeeds with no warnings; `tcFleetNaive` fails S2 on schedule 1 (robot 2 admitted under v0 to zone 1, which v1 closes); `tcFleetSanctionFairness` fails F1 on schedule 1, as intended; `tcFleetTwoPhase` found no bug in 3,442 schedules within a 30-second run (not the 100,000-schedule acceptance run of E1); `p compile --mode pobserve` generates the Java classes. The Java build, JUnit and PObserve replay have not been run (Gradle and Maven absent, no wrapper committed). The L3 monitor `AdaptationTerminates` and the event `eAdaptationAborted` were added after the evaluation and are not yet compiled. Evidence: [`reviews/evaluation-2026-10-21`](../../reviews/evaluation-2026-10-21/).

Everything else, and every prediction in experiments E0–E9, remains a hypothesis until it is recorded in the validation record (`MobileRobots/INSTRUCTIONS.md`, section 5).
